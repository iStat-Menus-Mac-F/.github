## What Is iStat Menus

iStat Menus is an advanced system monitor mac tool that replaces the standard menubar clock with a
customizable set of live readouts. Instead of opening a separate app, you keep CPU, GPU, memory,
network, disk, temperatures, fans and battery health visible at the top of the screen, each one
expanding into a detailed dropdown when you click it. The current release is version 7.20, and it
runs natively on Apple silicon and Intel Macs alike.

## Core Features

- **CPU and GPU load** — per-core graphs and a breakdown of the processes using the most power right now.
- **Memory** — a live view of used, active and cached RAM plus the apps eating the most memory.
- **Network** — real-time upload and download speeds, plus your public and local IP addresses on demand.
- **Disks** — free space, read/write activity and health for every mounted volume.
- **Sensors** — temperatures and fan speeds pulled straight from the hardware, so overheating is obvious.
- **Time and weather** — a rich menubar clock with a calendar, world clocks and a compact forecast.

## A Simple Workflow

Getting value out of istat menus mac download takes only a few minutes. Start by opening the app and
deciding which menubar items you actually want — most people keep CPU, memory and network on, and add
sensors if they run demanding software. Each item has its own settings pane where you choose the
combination of graph, text and icon that fits your bar.

From there, use the dropdowns as your first stop whenever something feels off. If the fans spin up,
click the sensors menu to see which component is heating up. If an app feels sluggish, the CPU and
memory menus show you the culprit without opening anything else. Because everything updates
continuously, you build an instinct for what "normal" looks like on your Mac, which makes the abnormal
jump out immediately.

## Tips and Shortcuts

Keep your menubar readable by using compact graphs rather than long text where you can — a small CPU
history graph conveys more at a glance than a bare percentage. Color-code the network item so upload
and download are easy to tell apart. If you have a notch-equipped Mac, trim the items you rarely check
so nothing gets hidden behind it. And take a moment to explore the calendar dropdown: it turns the
clock you were going to have anyway into a genuinely useful planner.

**Does it slow my Mac down?**
No. iStat Menus is built to be lightweight, sampling the sensors and system counters with minimal

**Can I hide the items I don't need?**
Yes. Every menubar item is independent — enable only the ones you want and configure each separately,
so your bar stays as minimal or as detailed as you like.
